# Equipamiento v0.17

Las geometrías, iconos, código y síntesis de efectos de esta actualización se crearon para Distrito Cero. No se importaron armas, escaneos, fotos, muestras sonoras o bibliotecas externas nuevas. Los nombres y parámetros son ficticios.

Los personajes, materiales humanos y vehículos previos conservan sus archivos y atribuciones, descritos en las versiones anteriores de este directorio. El nuevo kit `dc017-equipment.glb` contiene solamente trece utilerías virtuales originales, no un humano nuevo ni piezas funcionales para fabricación. Su origen, escala y materiales son para render de un videojuego.
