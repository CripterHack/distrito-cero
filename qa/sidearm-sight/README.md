# Referencia comparativa de apuntado · 0.20.1

`comparison.jpg` contiene antes/después del renderer de producción: dos equipos, mismo tamaño de viewport, cámara, luz y tiempo por pareja. La composición añade rótulos, sin retocar los personajes. `preview.jpg` usa reducción proporcional; `reference.json` conserva los informes y hashes de origen.

Las capturas se preparan y no representan FPS ni una aventura completa. La comparación de base permite registrar aserciones fallidas de alineación sin tratarlas como un run satisfactorio. La versión nueva exige todas las aserciones.

Inspección disponible en esta sesión: encuadre lateral reducido del avatar apuntando. Se comprueba la postura de los brazos y el contexto del objeto, pero la lectura fina de dedos, materiales y uniones a esa escala es limitada. Persisten siluetas de prenda/mano estilizadas. No equivale a una aprobación artística de toda la matriz ni de #5. La medición con paleta del renderer es independiente de esa evaluación.

No se incorporó un modelo generado ni se sustituyó la imagen del juego por un render externo. Consultar [SIDEARM-SIGHT.md](../../docs/project/SIDEARM-SIGHT.md) para criterios y límites.
